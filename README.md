# Personal Portfolio Website

A responsive personal portfolio website built to showcase my skills, projects, and contact information.

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- REST APIs

### Database
- MongoDB

## Features

- Responsive portfolio design
- Home, About, Skills, Projects, and Contact sections
- Project showcase
- Contact form
- Contact messages stored in MongoDB
- Projects fetched through REST API
- GitHub and LinkedIn links
- Clean and modern user interface

## Projects Included

### 1. Personal Portfolio
A personal portfolio website developed using HTML, CSS, and JavaScript.

### 2. E-Commerce Website
A full-stack e-commerce web application built using HTML, CSS, JavaScript, Node.js, Express.js, and MySQL.

### 3. Blog Platform
A full-stack blog platform developed using HTML, CSS, JavaScript, Node.js, Express.js, and MySQL.
